# Skill: Script Writer (เขียนบทคลิปสั้นความรู้)

## 1. กฎเหล็กการเขียนบท
- **ความยาวพากย์**: 25-45 วินาที (ประมาณ 80-120 คำไทย)
- **จำนวนฉาก**: 8-12 ฉาก ฉากละ 2-4 วินาที ภาพประกอบเปลี่ยนทุกฉาก
- **กลุ่มเป้าหมาย**: เด็ก 8 ขวบถึงผู้สูงอายุ ฟังเข้าใจทันทีโดยไม่ต้องมีพื้นฐาน
- **การเปรียบเทียบ**: ต้องมี Analogy เปรียบเทียบกับสิ่งใกล้ตัวอย่างน้อย 1 จุดในคลิป
- **Loop Ending**: ประโยคฉากสุดท้ายต้องส่งกลับไปเชื่อมกับประโยคเปิดในฉากที่ 1 ได้อย่างแนบเนียน

## 2. คำและประโยคต้องห้าม (Forbidden Phrases)
- ห้ามทักทาย: "สวัสดีครับ", "สวัสดีค่ะ", "ยินดีต้อนรับ"
- ห้ามเกริ่นนำ: "วันนี้เรามาดูกันว่า...", "เพื่อนๆ เคยสงสัยไหมว่า..."
- ห้ามขอ Engagement: "ฝากกดไลก์", "กดติดตาม", "คอมเมนต์บอกหน่อย"
- ห้ามใช้คำโอ้อวดเกินจริง: "ช็อกโลก", "99% ของคนไม่รู้", "ความลับที่หมอไม่บอก"
- ห้ามใส่ตัวเลข/ปี/ชื่อเฉพาะ หากไม่สามารถยืนยันจากแหล่งอ้างอิงชั้นต้นได้ 100%

## 3. ตัวอย่างเปรียบเทียบ (Good vs Bad)
- **ไม่ดี**: "สวัสดีครับทุกคน วันนี้เราจะมาพูดถึงเรื่องทำไมท้องฟ้าถึงเป็นสีฟ้ากันนะครับ ซึ่งเกิดจากปรากฏการณ์ Rayleigh Scattering..." (เกริ่นยืดเยื้อ ใช้ศัพท์เทคนิคทันที)
- **ดี**: "แสงอาทิตย์เป็นสีขาว แต่ทำไมเงยหน้ามองฟ้าแล้วเป็นสีฟ้า? ลองนึกว่าอากาศรอบตัวเราเต็มไปด้วยลูกบอลจิ๋วล่องหน..." (เข้าประเด็นทันที + เปรียบเทียบเห็นภาพ)

## 4. JSON Schema ของ `script.json`
```json
{
  "title": "ทำไมท้องฟ้าตอนกลางวันถึงเป็นสีฟ้า",
  "format": "why_question",
  "hook_used": "แสงอาทิตย์เป็นสีขาว แล้วสีฟ้าบนท้องฟ้ามาจากไหน?",
  "scenes": [
    {
      "id": 1,
      "narration": "แสงอาทิตย์เป็นสีขาว แล้วสีฟ้าบนท้องฟ้ามาจากไหน?",
      "visual": "Nong Roo looking up at a bright white sun beam splitting into rainbow rays in a clear blue sky",
      "emphasis_words": ["สีขาว", "สีฟ้า"],
      "claims": ["แสงอาทิตย์ที่ตามองเห็นเป็นแสงขาวซึ่งประกอบด้วยแสงหลายสีรวมกัน"]
    }
  ],
  "loop_note": "ฉากสุดท้ายจบด้วยคำว่า 'ก่อนที่แสงทั้งหมดจะเดินทางออกจากดวงอาทิตย์มาเป็น...' ซึ่งต่อเข้ากับ 'แสงอาทิตย์เป็นสีขาว' ในฉากแรกได้ทันที"
}
```
