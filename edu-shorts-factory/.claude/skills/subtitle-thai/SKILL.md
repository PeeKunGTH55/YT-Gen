# Skill: Subtitle Thai (ซับไตเติลภาษาไทยสำหรับคลิปสั้น)

## 1. หลักการสร้างซับไตเติล (`06_subtitles.py`)
- **ใช้ข้อความจากบทจริง (`script.json`)**: ห้ามใช้ข้อความดิบจาก STT ที่อาจสะกดคำไทยผิด
- **การตัดคำ**: ใช้ `pythainlp.word_tokenize(text, engine="newmm")` แล้วรวมคำให้ได้กลุ่มละ **3-6 คำ** (ไม่ฉีกคำประสมหรือเว้นวรรคผิดธรรมชาติ)
- **การคำนวณเวลา**: เทียบสัดส่วนจำนวนตัวอักษรของแต่ละกลุ่มคำเข้ากับความยาวเสียงจริงของฉากนั้น (`audio/manifest.json`) ทำให้ซับขึ้นตรงกับฉาก 100% ไม่เหลื่อมข้ามฉาก

## 2. การเน้นคำสำคัญ (`emphasis_words`)
- คำที่อยู่ในรายการ `scene.emphasis_words` จะถูกครอบด้วย ASS override tag เพื่อเปลี่ยนสีและขยายขนาดเล็กน้อย:
  ```text
  {\c&H0000D7FF&\fscx110\fscy110}คำสำคัญ{\c&H00FFFFFF&\fscx100\fscy100}
  ```

## 3. ตั้งค่า Header มาตรฐานของ `subs.ass`
- `PlayResX: 1080`, `PlayResY: 1920`
- `Alignment: 2` (Bottom Center)
- `MarginL: 80`, `MarginR: 180`, `MarginV: 520` (ลอยเหนือ Bottom Unsafe Zone 25% และไม่ชนปุ่มด้านขวา 15%)
- `Outline: 4`, `Shadow: 2` (ขอบดำหนา อ่านง่ายบนทุกสีพื้นหลัง)
